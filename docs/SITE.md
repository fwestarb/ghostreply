# Site e publicação / Website and publication

Site: https://fwestarb.github.io/ghostreply/

GitHub Pages: branch main, pasta /docs. Código React em website; comandos e manutenção em [website/README.md](../website/README.md).

O site usa fundo sólido, identidade visual própria, PT/EN, seis componentes React Bits, galeria com legendas de origem, recursos, instalação, uso, documentação e download real. O ZIP é uma cópia do código de aplicação no commit e595a34c5b2b80510aa0ee8fbee60b11857d4925, sem dependências instaladas, modelos ou segredos. Não é um instalador nem inclui o código do site. Hash em downloads/SHA256SUMS.txt e website/src/content.js.

The site is bilingual and includes source download, setup instructions and honest limitations. The ZIP snapshots application source only; dependencies, models and website source are excluded. Download integrity is checked before the browser receives the file.

## Verificação

[Testes do site](TESTE-SITE.json): idiomas e persistência, layouts 320/390/768/1440 px sem overflow, galeria por teclado, rolagem vertical, clipboard, FAQ, WebGL, alternativa sem WebGL, movimento reduzido e download com SHA-256, falhas e cancelamento. Isso verifica o site; não é um novo teste físico da câmera ou de integração com serviços externos.
